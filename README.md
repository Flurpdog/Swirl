# Swirl

A mobile app for capturing photos/video and applying creative effects,
built with Expo + React Native.

## Project state

This is early-stage. Start with these documents, in order:

1. [`SWIRL_PRODUCT_SPEC.md`](./SWIRL_PRODUCT_SPEC.md) — what Swirl is and
   isn't (draft, has open questions).
2. [`ROADMAP.md`](./ROADMAP.md) — phase breakdown and current status.
3. [`PRIVACY_ARCHITECTURE.md`](./PRIVACY_ARCHITECTURE.md) — data handling
   design.
4. [`LEGAL_AND_COMPLIANCE.md`](./LEGAL_AND_COMPLIANCE.md) — compliance
   checklist (not legal advice).
5. [`NOTES_UNVERIFIED.md`](./NOTES_UNVERIFIED.md) — **read this before
   running `npm install` or starting camera work.** Dependency versions
   in `package.json` are placeholders; npm registry access was blocked in
   the environment this scaffold was created in.

## Getting started (once npm access is available)

```
npm install
npx expo start
```

No camera functionality exists yet — see `ROADMAP.md` Phase 3.
